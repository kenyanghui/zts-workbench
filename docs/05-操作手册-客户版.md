## 快速上手

| 位置 | 怎么用 | 什么时候用 |
|---|---|---|
| 批次总览 | 本批结论、6 个指标、项目卡、类别/业主分布、审减 TOP、共性问题、最近动作 | 每天开始、向业主汇报 |
| 项目卷宗 | 点项目卡进入；页签：概览 / 材料 / 功能点或费用明细 / 技术评审 / 版本 / 审定表 | 逐项审核、复核、出结论 |
| 功能点审核 | 跨项目看功能点调整；按调整类型、ILF/EIF（或五类）筛选；点行看依据，采纳/驳回 AI 建议 | 功能点重认定 |
| 费用审核 | 基础设施/租用、运维、运营、第三方服务的价格来源与审减 | 费用口径复核 |
| 技术评审 | 形式/架构/一致性/绩效/价格/合同问题，按项目与严重度筛选 | 内部复核 |
| 知识库 | 六类来源；问答带引用；审核要点只用最新版 | 判定拿不准时找依据 |
| 审定表 | 送审/初稿/定稿/审减/依据；可打印 | 交付与归档 |
| 架构 | 主链路、四层、AI 流程、人机边界、部署安全 | 讲落地 |

## 先记住三件事

1. **AI 只做初稿**：分类、合并、依据匹配；采纳/驳回由评审人操作。
2. **结论必须带依据**：标准条款 + 历史案例 + 合同/采购价；定位不到就判存疑。
3. **只出结论不出整改建议**：审定表给总数和分项，甲方按审定价招标。

## 四类费用审核要点

| 类别 | 口径 | 常见审减 |
|---|---|---|
| 软件开发 | 财政两点法（ILF 35 / EIF 15）或南网五点法（10/7/4/5/4）×1.39×通用性系数 → 人天 ×2,600 元 | 过度拆分、EIF/ILF 误判、事务功能不计、一次性迁移不计 |
| 基础设施/租用 | 政府采购网均价 + 合同 | 高于采购价、合同缺页、范围外服务 |
| 运维 | 保修期内 8% / 保修期外 6.5% | 比例用错、基数重复 |
| 运营 | 人头/人天 + 工作量对标，无严格标准 | 人头虚高、缺绩效指标、增值配置无依据 |
| 第三方服务 | 合同范围 + 市场价 | 范围外不计、必要服务漏列（等保/密码测评） |

## 功能点判定要点

- ILF：本系统内维护、可独立增删改的数据组；只靠“修改/维护”关键词不可靠。
- EIF：只读引用外部系统数据组；数据在本系统内维护的改判 ILF。
- EO：通过计算对外输出；仅筛选/统计/呈现、无公式计算的是 EQ。
- 报表、查询、统计大屏、移动端适配、历史迁移：两点法不计。

## 多轮评审

- 初稿工作量最大；专家意见后出修改稿，一般修正两版，基于首稿修正、很少推翻。
- 打回规则：十条意见只响应一两条要打回；打回稿只看修改部分。
- 版本 V1/V2/V3 全部留痕，定稿锁定后出审定表。

## 交付物

- 结果件：审定报告（Word + Excel），只给结论和总数。
- 过程件：初稿表、评审意见、会议纪要。
- 财政评审另需内部流转报告（文字），供处室往来。

## 部署与安全

- 内网 / VPN / 自建 GPU 或可信云；开源模型本地化。
- RBAC、操作日志、版本留痕；数据不出域，不调用外部 API。
